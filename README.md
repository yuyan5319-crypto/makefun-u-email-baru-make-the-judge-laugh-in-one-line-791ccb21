One funny line, 200 characters or fewer, for the [make.fun bounty](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21).

## The line

> I finally organized my whole life into folders. 'Future Me' hasn't opened a single one.

## How it works

`main.ts` (Node, stdlib only, no network) writes the line to `/output/entry.txt`, where the competition gate scores it.

```sh
node main.ts
```
